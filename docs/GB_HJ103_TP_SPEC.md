## 2. 浓度分类（重点）

标准通过"**检测范围上限值的百分比**"来规定试验溶液浓度，因此必须实现三级分类。

### 2.1 量程分类

```
rangeOf(x) = x >= 4 && x <= 50 ? extended : basic      // 4 mg/L 为分界（含边界归扩展）
```
> 表 1 注：`*：测试溶液浓度相对于基本检测范围上限值（4 mg/L）的百分率。`

### 2.2 浓度水平分类（示值误差 / 重复性）

| 水平 | 基本范围（4 mg/L） | 扩展范围（50 mg/L） |
|---|---|---|
| 10% | 0.4 mg/L | — |
| 20% | 0.8 mg/L | — |
| 50% | 2.0 mg/L | 25 mg/L |
| 80% | 3.2 mg/L | 40 mg/L |

特殊浓度点：
- 24 h **低浓度**漂移：约 **0.1 mg/L**（3.6 定义：检测范围 0%～20%）
- 24 h **高浓度**漂移：**80%**（3.7 定义：检测范围 80%～100%）
- 定量下限：基本范围**下限值 0.02 mg/L**
- 实际样品比对：分界值 **0.4 mg/L**

判定容差建议 ±3%（如 0.8 mg/L 档接受 0.776～0.824），超出容差的样品归入"浓度不符"并在 UI 提示，但不阻断计算。

### 2.3 实际样品比对的浓度分类（核心）

```
if (实验室测定值均值 r_R < 0.4 mg/L)  → 用公式(12) 绝对误差，限值 ≤ 0.04 mg/L
if (实验室测定值均值 r_R >= 0.4 mg/L) → 用公式(13) 相对误差，限值 ≤ 10%
```
**注意：分界依据是"实验室标准方法（GB/T 11893）测定值的平均值"，不是仪器测定值。**

## 3. 公式（原文）

```
(1)  RE   = (r̄ − ρ) / ρ × 100%
(2)  S    = √[ Σ(r_i − r̄)² / (n−1) ]
(3)  LOQ  = 10 × S
(4)  RSD  = √[ Σ(r_i − r̄)² / (n−1) ] / r̄ × 100%
(5)  r̄_E  = Σ|r_i − r̄_0| / n
(6)  RD   = [ Σ|r_i − r̄_0| / n ] / r_UL × 100%
(7)  r̄    = Σ_{i=2..n} r_i / (n−1)
(8)  RE_1 = (r_1 − r̄) / r̄ × 100%
(9)  RE_2 = (r_2 − r_3) / r_3 × 100%
(10) RE_3 = (r_4 − r_5) / r_5 × 100%
(11) RE_4 = (r_6 − r_7) / r_7 × 100%
(12) r̄_E  = Σ|r_i − r_R| / n
(13) RE   = [ Σ|r_i − r_R| / n ] / r_R × 100%
(14) D    = D_e / D_t × 100%
(15) RSD_j = √[ Σ_{i=1..t}(ρ_ij − ρ̄_j)² / (t−1) ] / ρ̄_j × 100% , t = 3
(16) CD    = √[ Σ_{j=1..m} RSD_j² / m ] , m = 168
```

符号含义：
- `r_i` 第 i 次仪器测定值（mg/L）；`r̄` 测定值平均值；`ρ` 标准溶液浓度值（mg/L）
- `r_0̄` **最初 3 次**测定值平均值；`r_UL` 检测范围上限值
- `r_R` 标准方法（实验室）测定值的平均值
- `D_e` 实际有效数据个数；`D_t` 应获得的总数据个数
- `ρ_ij` 第 i 台仪器第 j 时段数据（i=1,2,3）

## 4. 逐项实现规格（13 项）

> 「条数」列是数据量校验（过少/过多提示）的依据。`n 次 @ 浓度` 表示该条件下需 n 条数据。

### 4.1 示值误差 — 5.5.1.1（基本）/ 5.5.2.1（扩展）

- **试验**：基本范围分别测 10%、20%、50%、80%（0.4/0.8/2.0/3.2 mg/L），1 h 测 1 次，**每种溶液连续 6 次**；扩展范围测 25 mg/L 连续 6 次。
- **公式**：(1)
- **计算**：每档 6 次取均值 `r̄`，`RE_i = (r̄_i − ρ_i)/ρ_i × 100%`；**取各档相对误差绝对值最大者**为判定值。
- **限值**：**±5%**（基本、扩展相同）
- **条数**：基本 4×6 = 24；扩展 6。

### 4.2 定量下限 — 5.5.1.2

- **试验**：测基本范围下限值 **0.02 mg/L** 标准溶液，**连续 7 次**。
- **公式**：(2) → (3)
- **计算**：`S` 为 7 次测定值的样本标准差（n−1）；`LOQ = 10 × S`。
- **限值**：**LOQ ≤ 0.02 mg/L**；同时该浓度**示值误差 ≤ ±30%**（公式1）。
- **条数**：7。

### 4.3 重复性 — 5.5.1.3（基本）/ 5.5.2.2（扩展）

- **试验**：基本范围 20% 与 80%（0.8/3.2）**各连续 6 次**；扩展范围 25 mg/L 连续 6 次。
- **公式**：(4)
- **计算**：每档算 RSD，**取较大值**为判定值。
- **限值**：基本 **≤2%**；扩展 **≤5%**。
- **条数**：基本 2×6 = 12；扩展 6。

### 4.4 24 h 低浓度漂移 — 5.5.1.4

- **试验**：约 **0.1 mg/L** 溶液，1 h 测 1 次，**连续 24 h（24 条）**。
- **公式**：(5)
- **计算**：`r̄_0` = 最初 3 次均值；`r̄_E = Σ|r_i − r̄_0| / n`，n 为全部测量次数（含前 3 次）。
- **限值**：**≤ 0.01 mg/L**（绝对量）
- **条数**：24（**严格按 24 条判定**；<24 条视为「数据不足 → 无法判定」，
  因为 24 h 漂移量的定义本身依赖完整的 24 个整点数据，用部分数据算出的
  平均绝对偏差会系统性偏小，不能作为结论）。

### 4.5 24 h 高浓度漂移 — 5.5.1.5（基本）/ 5.5.2.3（扩展）

- **试验**：80%（3.2）；扩展 80%（40）；1 h 1 次，连续 24 h。
- **公式**：(6)
- **计算**：同 (5) 的平均绝对偏差，再除以 `r_UL`（基本 4、扩展 50）× 100%。
- **限值**：基本 **≤1%**；扩展 **≤5%**。
- **条数**：24。

### 4.6 记忆效应 — 5.5.1.6

- **试验**：先连续测 **3 次 80%（3.2）**（结果不考核）→ 再依次测 **20%（0.8）7 次** → **80%（3.2）7 次**。
- **公式**：(7)(8)
- **计算**：对每种溶液，`r̄` = **第 2～7 次**均值（n=7，故分母 6）；`RE_1 = (r_1 − r̄)/r̄ × 100%`。
- **限值**：**80% → 20%：±10%**；**20% → 80%：±5%**（两个独立判定值）。
- **条数**：3（不考核）+ 7 + 7 = 17。

### 4.7 电压影响 — 5.5.1.7

- **试验**：80%（3.2）溶液；220 V 测 3 次 → 242 V 测 3 次 → 198 V 测 3 次。
- **公式**：(9)
- **计算**：`r_3` = 220 V 三次均值；`r_2` 分别为 242 V、198 V 三次均值；各算 `RE_2`，**取绝对值较大者**。
- **限值**：**±5%**
- **条数**：9（3+3+3）。

### 4.8 浊度影响 — 5.5.1.8

- **试验**：10%（0.4）溶液；无浊度 3 次 → 100 NTU 3 次 → 300 NTU 3 次。
- **公式**：(10)
- **计算**：`r_5` = 无浊度三次均值；`r_4` 为 100 NTU / 300 NTU 三次均值；取绝对值较大者。
- **限值**：**±15%**
- **条数**：9。

### 4.9 环境温度影响 — 5.5.1.9

- **试验**：80%（3.2）；顺序 **20℃ → 5℃ → 20℃ → 40℃ → 20℃**，每次变温后试剂稳定 **3 h**，随后连续测 **3 次**（共 5 段 × 3 = 15 条）。
- **公式**：(11)
- **计算**：`r_7` = 20℃ **9 次**（3 段）均值；`r_6` 为 5℃ 3 次均值或 40℃ 3 次均值；取绝对值较大者。
- **限值**：**±5%**
- **条数**：15（5 段 × 3）。

### 4.10 实际样品比对 — 5.5.1.10

- **试验**：选 5 种不同类型样品，覆盖基本范围；仪器连续测 **≥10 次**；同一样品由 1 家实验室按 **GB/T 11893** 重复测 **≥3 次**取均值 `r_R`。
- **公式**：`r_R < 0.4` 用 (12)；`r_R ≥ 0.4` 用 (13)
- **限值**：`<0.4 mg/L` → **≤0.04 mg/L**；`≥0.4 mg/L` → **≤10%**
- **条数**：每个样品 ≥10（建议 10）；需用户录入实验室均值 `r_R`。
- **UI 要求**：必须显式展示"本样品实验室均值 x.xxx < 0.4 mg/L → 采用绝对误差判定"这一分类说明。

### 4.11 最小维护周期 — 5.5.1.11

- **计算**：任意 2 次维护间隔（h），取最小值。
- **限值**：**≥ 168 h**
- **条数**：≥2 个时间点。

### 4.12 数据有效率 — 5.5.1.12

- **公式**：(14)
- **计算**：`D = D_e / D_t × 100%`；有效数据定义见 5.5.1.12 a/b 条。
- **限值**：**≥90%**（越大越好）
- **条数**：1 组（有效数 / 总数）。

### 4.13 一致性偏差 — 5.5.1.13

- **试验**：**3 台**仪器同时测同一浓度溶液，1 h 1 次，共 **168 组**（每时段 3 台各 1 条）。
- **公式**：(15)(16)
- **计算**：每个时段 j 先求 3 台的 `RSD_j`，再 `CD = √(Σ RSD_j² / m)`，m=168。
- **限值**：**≤10%**；当某 `RSD_j > 10%` 时直接视为 `CD > 10%`（判不合格）。
- **条数**：168 × 3 = 504。

## 5. 判定规则

```
higherIsFail = true（大多数项）: pass = (|metric| <= limit)
higherIsFail = false（数据有效率、维护周期）: pass = (metric >= limit)
无法判定: 数据不足 / 分母为 0 / 数据缺失 → 结论 = "无法判定"，不参与合格统计
```

**总体结论（`CalcSession.overall`）**：

```
有任一不合格                  → 不合格
有任一「无法判定」             → 无法判定
验证项没算全（reports < 应算项数）→ 无法判定
全部通过且算全                 → 合格
```

> 后两条是合规底线：**部分项目通过不足以证明仪器满足标准要求**，
> 既不能凭「1 项通过 + 12 项未判定」判合格，也不能凭「13 项里只算 1 项」判合格。

**分段级的部分验证（`GbSegment.enabled`）**：

用户手上可能只有某一档浓度的数据（例如示值误差只有 0.8 mg/L 的 6 条）。
允许用户**只勾选有数据的分段**参与计算，未勾选的分段不报「数据不足」。此时：

```
该项数值照常计算并记录（结果页显示「（参考）x.xx %」）
但结论 = 无法判定，备注标明「本次仅验证 1/4 个分段，按标准该项需全部 4 个
分段方能判定，故本次结果仅作记录」
```

即：**可以记录，不给出合格结论**。理由与 P0-2 同源——标准要求 4 个浓度档
全部验证，只验 1 档不能得出「示值误差合格」的结论，但用户仍然需要看到
这一档算出来的数（用于自查仪器状态）。

**分段「可用」的判定（`GbCalculator.segmentUsable`）**：

设置页进入时是否**默认勾选**某个验证项，看的是「该项是否至少有一个可用的分段」。
可用 = 条数够 **且** 浓度对得上：

```
条数：segment.samples.length >= spec.required
浓度：|段均值 − spec.target| / spec.target <= concentrationMatchTolerance (0.5)
discard 段：只要求非空（它是标准规定的前置步骤，不参与判定）
```

只按条数判断会出两个假阳性：

1. **单段带目标浓度的项**（定量下限 target 0.02、24h 低浓度漂移 target 0.1）：
   `autoBindByLevel` 把**所有行**塞进唯一分段，于是「手里只有 0.8 mg/L 数据」
   的用户也会看到定量下限被默认勾上，算出一个拿 0.8 的数据去比 0.02 的定量下限
   结论——数值毫无意义。
2. **条件顺序项**（电压 / 浊度 / 环境温度 / 一致性偏差）：分段共用同一目标浓度、
   按行序切开，6 条数据会被切成 3/3/0，每段都「看起来够」。这类项由
   `_isConditionSequenceItem` 单独排除（一致性偏差各段 target 全为 null，
   同样按此处理），不靠浓度校验。

此外，**缺 discard 段视为整个验证项不可用**：记忆效应要求先测 3 次 80% 再切到
20%，缺了前置段，那批 20% 数据就不是「切换后」的测量值，算出的记忆效应不成立。

**舍入策略**：判定使用**未舍入**的原始计算值；展示时按项舍入（mg/L → 3 位小数；% → 2 位小数）。避免"0.0099 显示 0.01 就判不合格"的歧义，导出 Excel 时同时写入原始值与展示值。

## 7. 数据来源映射（OCR 表 → 计算输入）

| OCR 列 | 用途 | 是否参与计算 |
|---|---|---|
| 时间 | 排序、24 h 连续性校验、时段编号 j | 是（分组/校验） |
| **数据结果** | 测定值 `r_i`（mg/L） | **是（唯一计算量）** |
| 吸光度 | 过程量展示 | 否 |
| 数据标识 | 有效性（`N` 视为正常；空/其他视为异常） | 是（默认排除） |
| 当前值 / 空白值 | 过程量展示 | 否 |

标准溶液浓度 `ρ`、实验室均值 `r_R`、仪器台号等**无法从 OCR 表获得**，必须由用户在计算设置页手动录入。
