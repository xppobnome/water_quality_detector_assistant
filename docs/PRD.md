# 水质检测仪助手 — 产品需求文档（简单 PRD）

## 1. 项目信息

| 项目 | 内容 |
| --- | --- |
| Language | 中文（简体） |
| Programming Language | Flutter / Dart（沿用现有空壳项目，非 Web 技术栈） |
| Project Name | water_quality_detector_assistant |
| 目标平台 | Android 手机端 + Windows 桌面端（响应式，同一套代码） |
| 当前状态 | Flutter 默认模板（`lib/main.dart` 为计数器示例，`pubspec.yaml` 默认依赖） |

**原始需求复述**：在现有 Flutter 空壳项目上开发一款「水质检测仪助手」应用，蓝白配色，同时适配 Android 手机与桌面端。核心能力包括：① 手机与电脑同一局域网下的数据传输；② 拍照/选图 OCR 识别三种检测仪表格数据并合并生成 Excel（自动去重）；③ 大肠杆菌吸光度计算与一次函数拟合（按通道分类，绘制图像并输出 A/B/R²）。

**三种检测仪表格结构（OCR 需适配）**：
1. 总大肠菌群检测仪（MCGS 屏）：采样日期、采样时间、总大肠杆菌、单位(MPN/L)、空白对照、测试对照（含小数与「未检出」文本）。
2. 在线水质分析仪（E.co 大肠菌群屏）：采样日期、采样时间、通道、分析结果、空白、检测；通道三类 = 大肠埃希氏菌B / 总大肠菌群A / 菌落总数C。
3. 总铜在线分析仪：时间、数据结果、吸光度、数据标识、当前值、空白值（小数）。

## 2. 产品定义

### 2.1 产品目标（3 个正交目标）

1. **打通现场数据流转**：让用户摆脱手工抄录，通过局域网把手机端已分析的水质数据可靠传输到电脑端，实现「采集—传输—汇总」闭环。
2. **图片数据一键结构化**：将三种检测仪屏幕截图/照片经 OCR 识别为结构化表格，自动去重并合并导出为一个 Excel 文件，减少人工录入错误与重复劳动。
3. **标准化的计算能力**：按通道分类完成大肠杆菌吸光度计算与一次函数拟合，自动输出 A、B、R²，并支持「是否计算其他值」扩展，替代手工计算。

### 2.2 用户故事

1. 作为现场检测人员，我希望用手机拍下检测仪屏幕，应用能自动识别表格数据并合并成一个去重后的 Excel，这样我就不用手工抄表和整理数据。
2. 作为实验分析人员，我希望在识别出的表格中选择一行空白数据和一行含菌数据、输入标液浓度与单位后，应用能自动算出吸光度、拟合一次函数并展示 A/B/R²，这样我能快速得到标准曲线结果。
3. 作为实验分析人员，我希望能按通道（大肠埃希氏菌B / 总大肠菌群A / 菌落总数C）分类选择与计算，这样不同通道的数据不会被混算导致结果错误。
4. 作为现场用户，我希望手机与电脑在同一 WiFi 下能扫码或自动发现设备建立连接并选择文件传输，这样我不用数据线也能把数据搬到电脑上。
5. 作为桌面端用户，我希望应用在宽屏下使用左侧导航栏、在手机上使用底部导航栏，这样操作入口清晰且符合各自平台习惯。

## 3. 技术规范

### 3.1 需求池（按优先级）

#### P0（必须完成，MVP 核心）

- **P0-1 应用骨架与响应式布局**：蓝白配色体系（主色 `#1976D2`，浅蓝底 `#E3F2FD`，辅以白/中性灰）；手机端底部导航栏、桌面端左侧导航栏；四页路由：首页（功能入口）、图片转 Excel、大肠杆菌计算、设置（数据传输）。
- **P0-2 图片转 Excel（功能1）**：拍照 / 多选图片 → OCR 识别（中文+数字，优先 `google_mlkit_text_recognition`）→ 解析为表格行 → 合并为一个 Excel（`excel` 或 `syncfusion_flutter_xlsio`）→ 自动去重。去重规则：整行数据相同即去重；以「采样日期 + 采样时间 + 通道/仪器类别」为判定键。
- **P0-3 三种仪器表格结构适配**：按仪器类型区分列结构并映射（总大肠菌群检测仪 / E.co 在线水质分析仪 / 总铜在线分析仪），正确处理整数、小数与「未检出」文本。
- **P0-4 大肠杆菌计算（功能2）**：识别后提示选择「一行空白数据」与「一行含菌数据」；输入标液浓度（默认 9000）与单位（默认 MPN/L）；计算吸光度 `ln(空白/检测) * 10000`（若空白 < 检测则用 `ln(检测/空白)`），得到两个吸光度值；以 `(0, 空白吸光度)` 与 `(标液浓度, 含菌吸光度)` 拟合一次函数 `y = aX + b`，输出 `a`（即 B）、`b`（即 A）、拟合度 R²，并绘制图像。
- **P0-5 数据传输（功能A，核心）**：设置页提供「数据传输」；手机与电脑同局域网下，电脑端展示二维码供手机扫码连接，或显示同一网络下可发现的手机设备列表；连接成功后任一端可选文件传输。技术方向：`HttpServer` + UDP 广播发现 + `mobile_scanner` 扫码，桌面端展示二维码。

#### P1（应该完成，提升可用性）

- ~~P1-1 计算扩展开关~~：**已取消**（需求方决定先去掉「计算其他值」，本版本不实现）。
- **P1-2 识别结果人工校正**：OCR 识别结果以可编辑表格展示，支持用户修正识别错误后再导出。
- **P1-3 仪器类别选择/切换**：图片转 Excel 页支持手动指定仪器类型（总大肠菌群 / E.co / 总铜）作为列映射依据。
- **P1-4 传输进度与结果反馈**：传输过程展示进度、成功/失败状态、文件列表与重试。

#### P2（可延后，锦上添花）

- **P2-1 历史记录**：本地保存识别/传输历史，支持查看与再次导出。
- **P2-2 数据预览图表**：对 Excel 数据做简单趋势/汇总预览。
- **P2-3 计算报告导出**：将 A/B/R² 与拟合图导出为图片或 PDF。

### 3.2 UI 设计要点

- **整体风格**：蓝白主色调；卡片式布局；大标题 + 清晰主操作按钮；状态色用语义色（成功绿/警示橙/错误红）。
- **导航**：手机端底部 `NavigationBar`（首页 / 图片转 Excel / 大肠杆菌计算 / 设置）；桌面端左侧 `NavigationRail`（宽屏可扩展为抽屉）。
- **首页**：功能入口卡片（图片转 Excel、大肠杆菌计算、数据传输），可带简要说明与图标。
- **图片转 Excel 页**：顶部「拍照 / 从相册选择（多选）」按钮 → 图片缩略图列表 → 仪器类型选择 → 识别结果可编辑表格 → 底部「合并去重并导出 Excel」。
- **大肠杆菌计算页**：识别结果表格（可勾选行）→ 选择「空白行 / 含菌行」→ 输入标液浓度与单位 → 「是否计算其他值」开关 → 拟合图像展示区 → 结果卡片（A、B、R²）。
- **设置页（数据传输）**：连接方式切换（扫码 / 设备列表）；桌面端显示二维码；传输文件列表与进度。

### 3.3 已确认决策（来自需求方澄清）

1. **数据传输内容**：**文件级传输**——传输具体的 Excel/图片等文件，任一端浏览选择本地文件后发送到对端。
2. **拟合变量命名**：确认 `a = B`（斜率）、`b = A`（截距），即拟合 `y = aX + b` 中斜率 a 显示为 B、截距 b 显示为 A。
3. **「未检出」处理**：吸光度/拟合计算**只使用「空白」和「检测」两列的值，不使用「分析结果」栏内容**；空白/检测为空或非数值时按异常值处理（跳过并提示）。
4. **OCR 引擎（更新）**：`google_mlkit_text_recognition` 仅支持 Android/iOS，不支持 Windows/Linux/macOS，且 Dart 条件导入无 Windows 专属标记，无法干净隔离到移动端编译单元。因此改用**可配置的云端 OCR 适配器**（`http` 包，跨平台通用）：移动端/桌面端均通过 HTTP 调用用户配置的 OCR 服务地址识别图片。桌面端图片来源支持「点击选择 / 粘贴（Ctrl+V）/ 虚线区点击」；移动端保留拍照与相册多选。OCR 服务地址在「设置」中配置。
5. **去重键的「仪器类别」**：无「通道」字段的仪器（总铜、总大肠菌群 MCGS）以「仪器类型」代替「通道」作为判定键的一部分。
6. **桌面端二维码内容格式**：`{协议版本}|{IP}:{端口}|{token}`（具体字段由架构师定义，token 用于配对鉴权）。
7. **标液浓度默认值**：默认 9000、单位 MPN/L，全通道统一；用户可按通道分别修改。
